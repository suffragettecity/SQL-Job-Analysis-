# Exploratory Data Analysis w/ SQL: Job Market Analysis

An SQL project analyzing the data engineer job market using real world posting data. This showcases my ability to **write production-quality analytical SQL, design efficient queries, and turn business questions into data-driven insights**.

## Summary

**Project Scope:** Built 3 analytical queries that answer key questions about the data engineering gob market

**Data Modeling**: used multi-table joins across fact and dimension tables to extract insights

**Analytics**: applied aggregations, filtering, and sorting to find top skills by demand, salary, and overall value

**Outcomes**: delivered actionable insights on SQL/Python dominance, trends, and salary patterns
